## 项目说明

韩语背单词微信小程序的数据知识库与产品设计文档集合。

**产品定位：** 辅助韩语学习者通过「主动回忆 + SRS 科学记忆」高效背单词，微信小程序形态，碎片时间即学。

**当前阶段：** 通用三级词书已进入小程序开发；TOPIK 初级/中级/高级数据已交付，产品接入与音频仍待完成。

### 测验数据（*_quiz.json）

每个词对应 3 个同词性干扰选项，供四选一选择题使用。

### 音频数据（音频_edge女声正式版/）

音频使用 Edge TTS 韩语女声生成，并以 `level + id` 与词库唯一绑定。

| 项目 | 规则 | 示例 |
|------|------|------|
| 本地文件名 | `{level}_{id:04d}.mp3` | `beginner_1019.mp3` |
| 本地相对路径 | `音频_edge女声正式版/{level}/{level}_{id:04d}.mp3` | `音频_edge女声正式版/beginner/beginner_1019.mp3` |
| 云存储路径 | `audio/{level}/{id}.mp3` | `audio/beginner/1019.mp3` |

当前音频仅覆盖通用三级词书；TOPIK 三本音频尚未生成。现有清单：

- `音频_edge女声正式版/audio_manifest.json`：全量音频 manifest，包含 `level`、`id`、`korean`、`meaning`、`filename`、`audio`、`cloud_path`、`batch`、`exists`。
- `音频_edge女声正式版/audio_batch2_manifest.json`：第二批新增词音频清单。
- `音频_edge女声正式版/audio_batch2_summary.json`：第二批音频汇总。

音频批次：

### 字段说明

| 字段 | 说明 |
|------|------|
| id | 序号，级别内从 1 连续编号 |
| korean | 韩语单词（한글） |
| pronunciation | 发音罗马字标注（基于实际发音） |
| pos | 韩语词性标注 |
| pos_cn | 对应中文词性 |
| meaning | 中文释义 |

## 发音标注说明

采用韩国《国语罗马字标记法》(Revised Romanization)，基于实际发音标注：

- 音节间用连字符 `-` 分隔
- 必须反映经音化、鼻音化、连音等音变规则

详细罗马字对照表见 `CLAUDE.md` 发音标注规范段。

## 词汇来源与版权

通用三级词书基于韩语通用高频词汇自行编排。TOPIK 中高级词书采用官方分级资料、官方学习词典与公开 TOPIK 词表交叉审计：

- 韩国国立国语院（국립국어원）公开语料库词频数据
- 韩国国立国语院 2003 学习用词汇目录与 2017 标准课程 1-6 级词汇目录
- 韩国国立国语院《韩国语基础词典》中文版与《标准国语大辞典》
- NIIED / 中国教育考试网公开的 TOPIK 等级边界
- 两套公开 TOPIK II 逐词表，仅作为候选佐证

> TOPIK 官方不发布唯一固定的逐词考纲。本项目文件是交叉审计形成的备考词书，不得宣传为“TOPIK 官方词表”。逐词来源、排除项和公开来源误释修正见 `TOPIK中高级词汇来源审计.md` 与 `TOPIK中高级词汇元数据审计.md`。

**本词汇表不构成对任何教材、词典的复制或改编**，单个词汇及其释义属于语言事实（不受著作权保护），编排方式为原创。

## 编辑指南

- 修改 JSON 后保持格式正确、ID 连续
- 添加新词时递增 id；已接入音频的旧词不要改 id
- pos 字段使用韩语词性名（명사/동사/형용사/부사/감탄사/조사/관형사/대명사/수사）
- 新增词后需补音频并更新 `audio_manifest.json` 与对应批次清单
- 修改后运行 `python3 memory-bank/工具脚本/update_index.py` 更新文档索引
- 所有 .md 文档须包含标准头信息（详见 `文档管理规范.md`）
