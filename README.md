## 数据格式

### 词汇数据（memory-bank/数据文件/beginner/intermediate/advanced.json）

```json
{
  "level": "beginner",
  "level_cn": "初级",
  "description": "级别描述",
  "total": 1018,
  "words": [
    {
      "id": 1,
      "korean": "사람",
      "pronunciation": "sa-ram",
      "pos": "명사",
      "pos_cn": "名词",
      "meaning": "人"
    }
  ]
}
```

### 测验数据（*_quiz.json）

每个词对应 3 个同词性干扰选项，供四选一选择题使用。

### 字段说明

| 字段 | 说明 |
|------|------|
| id | 序号，级别内从 1 连续编号 |
| korean | 韩语单词（한글） |
| pronunciation | 发音罗马字标注（基于实际发音） |
| pos | 韩语词性标注 |
| pos_cn | 对应中文词性 |
| meaning | 中文释义 |

## 发音标注说明

采用韩国《国语罗马字标记法》(Revised Romanization)，基于实际发音标注：

- 音节间用连字符 `-` 分隔
- 必须反映经音化、鼻音化、连音等音变规则

详细罗马字对照表见 `CLAUDE.md` 发音标注规范段。

## 词汇来源与版权

本词汇表基于韩语通用高频词汇自行编排，选词参考以下公开资源的词频统计规律：

- 韩国国立国语院（국립국어원）公开语料库词频数据
- 韩国语能力考试（TOPIK）各级别词汇范围的公开信息

**本词汇表不构成对任何教材、词典的复制或改编**，单个词汇及其释义属于语言事实（不受著作权保护），编排方式为原创。

## 编辑指南

- 修改 JSON 后保持格式正确、ID 连续
- 添加新词时递增 id
- pos 字段使用韩语词性名（명사/동사/형용사/부사/감탄사/조사/관형사/대명사/수사）
- 修改后运行 `python3 memory-bank/工具脚本/update_index.py` 更新文档索引
- 所有 .md 文档须包含标准头信息（详见 `文档管理规范.md`）
