# Figma 原型生成 Prompt

> 创建日期：2026-05-31
> 用途：复制每个页面的 prompt 到 Figma AI 插件中生成原型，再手动调整细节
> 设计规范：浅绿色主题、白底、大圆角(16px)、大留白、韩式极简风格

---

## 全局设计规范

```
画布尺寸：375 × 812（iPhone标准）
主题色：#A8D5BA（浅绿）
强调色：#7BC4A0（深一度绿，用于按钮）
背景色：#FFFFFF
卡片背景：#F8FBF9（极浅绿灰）
文字主色：#2D2D2D
文字辅色：#999999
错误色：#FF6B6B
成功色：#4CAF50
圆角：卡片16px，按钮12px，小标签8px
字体：系统默认（微信小程序环境）
底部导航栏高度：56px
```

## 页面 1：单词首页

### Prompt

```
设计一个韩语背单词小程序的首页，iPhone尺寸375×812，白色背景，浅绿色(#A8D5BA)主题。

顶部区域：
- 背景色为浅绿色渐变(从#A8D5BA到#D4EFE0)，高度约160px，大圆角底部
- 左上角小字"안녕, 오늘도 화이팅～"，字号14px，白色
- 右侧放一个简约的小图标（书本或叶子造型），装饰用

中间卡片区（白色卡片，16px圆角，带浅阴影）：
- 卡片分两栏横向排列
- 左栏：当前词书名称"初级词汇"，下方小字"已学182/1018词"，右箭头图标表示可点击
- 右栏：今日进度"今日已学 12词"，下方小字"复习 5词"

打卡签到区：
- 小卡片样式，浅绿背景，左侧日历图标
- 文案"每日签到"，右侧显示"已签到 7天"或"点击签到"按钮

两个主入口按钮（纵向排列，间距12px）：
- "背单词 · 10词" — 大按钮，浅绿色(#A8D5BA)填充，白色文字，高度56px，圆角12px
- "复习 · 12词" — 大按钮，白色底+浅绿色边框，绿色文字，高度56px，圆角12px

底部Tab导航栏：
- 3个tab：单词（书本icon）、统计（图表icon）、我的（人像icon）
- 当前选中"单词"tab，图标和文字为主题绿色，其他为灰色
- 白色背景，顶部1px浅灰分割线
```

## 使用说明

1. 在 Figma 中安装 AI 插件（推荐 Codesign AI 或 Wireframe Designer）
2. 按页面逐个复制上方 prompt
3. 生成后根据实际效果微调：
   - 主题色统一为 #A8D5BA
   - 确保圆角统一 16px/12px
   - 留白要足够大（韩式极简核心）
4. 将各页面用 Figma 原型连线串起交互流程

### 交互连线参考

```
首页 "背单词" → 四选一页
四选一 选对 → 主动回忆页（同一词）
四选一 选错 → 答案详情页 → 下一词（四选一）
主动回忆 任意按钮 → 答案详情页 → 下一词
最后一词详情页 "下一词" → 结算页
结算页 "再学一组" → 四选一页（新一组）
结算页 "休息一下" → 首页
首页 "换词书" → 选词书页
```
