## 一、需求背景

### 1.1 市场现状

韩语学习市场存在明确空白：

| 现有产品 | 优势 | 缺陷 |
|----------|------|------|
| 不背单词 | 科学记忆机制（主动回忆+SRS） | 仅支持英语 |
| 韩语U学院 | 韩语垂类覆盖 | 无主动回忆、无SRS、纯浏览 |
| 多邻国 | 游戏化留存 | 韩语内容质量一般，不系统 |
| 疯狂背单词 | 多模式练习 | 仅英语，四选一被动识别 |

**核心发现：没有任何产品同时做到「韩语 + 主动回忆 + SRS 科学记忆」。**

### 1.2 形态选择

选择微信小程序而非原生 App：

| 维度 | 小程序优势 |
|------|-----------|
| 获客 | 即开即用，无需下载，微信社交裂变 |
| 场景 | 碎片时间学习，3-5 分钟一组 |
| 开发 | 成本低，迭代快，一人可完成 MVP |
| 竞争 | 所有竞品均为原生 App，小程序形态无直接竞争 |

## 二、产品目的与目标

### 2.1 产品定位

辅助韩语学习者进行韩语背诵，提升韩语能力。

### 2.2 产品目标

| 阶段 | 目标 |
|------|------|
| MVP（V1） | 完成背单词+复习双模块闭环，跑通程序。
| V2 | 补充例句、打卡分享裂变、学习数据可视化 |
| V3 | 多模式练习（听写、拼写）、随身听 |

### 2.3 成功指标

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 次日留存 | ≥40% | 高于同类工具平均（30%） |
| 单次学习完成率 | ≥80% | 开始一组 10 词后完成的比例 |
| 7日留存 | ≥25% | Streak 机制驱动 |
| 平均单次时长 | 3-5 分钟 | 匹配碎片化场景 |

## 三、目标用户
有韩语学习需求的人群；韩语爱好者但无法坚持背单词的人。
### 3.1 核心画像

| 维度 | 描述 |
|------|------|
| 年龄 | 18-35 岁 |
| 性别 | 女性为主（韩语学习者性别分布） |
| 动机 | 追星/韩剧/韩综/旅行/留学/兴趣 |
| 水平 | 零基础 ~ TOPIK II（已认识字母，但词汇量不足） |
| 场景 | 通勤、午休、睡前等碎片时间 |
| 痛点 | 背了就忘、坚持不下来、现有工具太重或不够科学 |

### 3.2 用户分层

| 类型 | 特征 | 我们的应对 |
|------|------|-----------|
| 纯新手 | 认识字母但几乎没词汇量 | 从初级词库第 1 词开始，按序推送 |
| 有基础 | 已知部分常用词（追剧积累） | 「熟」按钮快速跳过已知词 |
| 备考型 | 目标 TOPIK 考试 | 分级对应 TOPIK I/II，换词书选择级别 |

## 五、需求详述 — 背单词模块

### 5.1 入口与配置

| 项目 | 方案 |
|------|------|
| 入口 | 首页「背单词」按钮 / 「开始学习」按钮 |
| 每次数量 | 可选 5/10/15（在选词书页设置） |
| 出词顺序 | 按词库顺序推送（尊重分级设计，从易到难） |
| 预计时长 | 10 词 ≈ 3~4 分钟 |

### 5.2 背单词页面元素

每个单词卡片包含：
- 韩语单词
- 播放 icon（点击播放单词发音）
- 「熟」按钮（点击后该词永不再出现，复习中也不出现）
- 收藏 icon
- 单组学习进度条
- 引导文案（小字）：从下列四个选项中，选择正确答案
- 返回按钮（点击回到单词首页）

### 5.3 两阶段验证机制（四选一 → 主动回忆）

**每个词必须通过两关才算记住：先通过四选一（被动识别），再通过主动回忆（主动产出）。**

**完整流程：**

```
词A 首次出现 → 四选一页面
  ├── 选对 → 紧接展示主动回忆页面（同一个词）
  │     ├── 记得 → 通过✅ 本组不再出现
  │     ├── 模糊 → 插入队列，下次重现直接展示主动回忆
  │     └── 忘记 → 插入队列，下次重现回到四选一
  ├── 选错 → 展示释义，插入队列，下次重现还是四选一
  └── 不太记得 → 展示释义，插入队列，下次重现还是四选一

重现时：
  - 上次在四选一阶段失败 → 再走四选一
  - 上次在主动回忆点了模糊 → 直接展示主动回忆
  - 上次在主动回忆点了忘记 → 退回四选一
```

**页面类型 A：四选一选择题**

```
┌────────────────────────────┐
│  ← 返回          3/10 ━━━  │  ← 进度条
│                            │
│        사랑         🔊 ♥   │  ← 韩文 + 播放 + 收藏
│                   [熟]     │
│                            │
│  从下列四个选项中，选择正确答案  │  ← 引导文案（小字）
│                            │
│  ┌────────────────────┐    │
│  │      爱，爱情       │    │  ← 选项1（正确）
│  └────────────────────┘    │
│  ┌────────────────────┐    │
│  │      水             │    │  ← 选项2（干扰）
│  └────────────────────┘    │
│  ┌────────────────────┐    │
│  │      天空           │    │  ← 选项3（干扰）
│  └────────────────────┘    │
│  ┌────────────────────┐    │
│  │      花             │    │  ← 选项4（干扰）
│  └────────────────────┘    │
│                            │
│       「不太记得」          │  ← 底部按钮
└────────────────────────────┘
```

选择后的反馈：
- 点击正确选项 → 正确答案标绿，紧接进入主动回忆页面（同一个词）
- 点击错误选项 → 错误标红 + 正确标绿，展示释义详情，出现「下一词」按钮
- 点击「不太记得」→ 展示同正确答案的详情页面，出现「下一词」按钮

**页面类型 B：主动回忆**

```
┌────────────────────────────┐
│  ← 返回          5/10 ━━━  │  ← 进度条
│                            │
│        학교         🔊 ♥   │  ← 韩文 + 播放 + 收藏
│                   [熟]     │
│                            │
│                            │
│      （空白区域）            │  ← 无选项，用户自行回忆
│                            │
│                            │
│                            │
│  ┌──────┐┌──────┐┌──────┐ │
│  │ 记得 ││ 模糊 ││ 忘记 │ │  ← 三级反馈
│  └──────┘└──────┘└──────┘ │
└────────────────────────────┘
```

点击按钮后的反馈：
- 点击「记得」→ 展示正确释义详情页面，该词通过✅
- 点击「模糊」→ 展示正确释义详情页面，插入队列（下次重现仍为主动回忆）
- 点击「忘记」→ 展示正确释义详情页面，插入队列（下次重现退回四选一）

### 5.4 答案揭示详情页（两种页面共用）

无论通过哪种方式触发（选对/选错/不太记得/记得/模糊/忘记），展示：

```
┌────────────────────────────┐
│                            │
│        사랑         🔊     │
│      sa-rang               │  ← 发音标注
│     명사 · 名词             │  ← 词性
│                            │
│        爱，爱情             │  ← 正确释义
│                            │
│      ──────────            │
│      「下一词」             │  ← 主按钮
└────────────────────────────┘
```

最后一词点击「下一词」→ 跳转结算页。

### 5.5 SRS 频率规则（背新词时）

**通过条件：四选一选对 + 主动回忆点记得 → 该词本组不再出现。**
**未通过 → 会话内重现，直到通过或达到 5 次上限。**

| 通过方式 | SRS 行为 |
|----------|----------|
| 首次就通过（四选一选对 + 主动回忆记得） | interval = 1 天, ease = 2.5 |
| 重学后通过 | interval = 1 天, ease = 2.3 |
| 5 次仍未通过 | interval = 1 天, ease = 1.3，标记困难词 |

### 5.6 会话内重学机制

**触发条件：四选一选错/不太记得，或主动回忆点模糊/忘记**
**通过条件：四选一选对 + 主动回忆点记得（两阶段都通过）**

```
当前队列：词1 词2 词3 词4 词5 词6 词7 词8 词9 词10

用户在 词3 未通过 → 看完释义 → 点「下一词」
                ↓
词3 被插入 3~5 个词之后的位置（如 词7 后面）
                ↓
队列变为：词4 词5 词6 词7 [词3重现] 词8 词9 词10
                ↓
词3 重现时的页面类型：
  - 四选一阶段失败（选错/不太记得）→ 重现为四选一
  - 主动回忆点模糊 → 重现为主动回忆
  - 主动回忆点忘记 → 重现为四选一（退回）
                ↓
如果这次两阶段都通过 → 设置 SRS（ease=2.3）
如果又未通过 → 再次插入队列（最多循环 5 次）
                ↓
5 次仍未通过 → 标记困难词，设 interval=1, ease=1.3
              → 明天复习模块优先推送
```

### 5.7「熟」按钮机制

| 项目 | 说明 |
|------|------|
| 位置 | 每个单词卡片上均有 |
| 触发 | 任何时刻点击「熟」按钮 |
| 系统行为 | 该词标记为"已移除"，永不再出现在背单词和复习模块中 |
| 查看位置 | 「我的」→「近日已学」→「已完全记得不再出现」tab |
| 适用场景 | 用户已完全掌握的词（如韩剧常见词） |

### 5.8 会话结束 → 结算页

| 条件 | 行为 |
|------|------|
| 本组单词全部完成（含重学通过） | → 跳转结算页 |
| 本组单词全部标记「熟」 | → 直接跳转结算页 |
| 用户点返回按钮 | → 已完成的词正常保存，未完成的下次继续 |

### 5.9 边界场景规则

| 场景 | 规则 |
|------|------|
| 中途退出（如背了 2/10 词） | 下次点「背单词」继续剩余 8 词，不重新开组 |
| 数据写入时机 | SRS 参数 + position 均在一组全部完成后批量写入，中途退出不写入 |
| 重学词插入顺序 | 多个词触发重学时，按失败先后顺序依次插入队列 |
| 重学插入位置不足 | 队列剩余不足 3 词时，重学词插到最后一位 |
| 组内全部点「熟」 | 0 词走流程，直接跳结算页 |
| 点「熟」后进度条 | 分母不变（仍显示 X/10），该词视为已完成 |
| 背词过程中切换词书 | 允许，需先退出当前组（点返回），再去首页换词书 |
| 词书全部背完 | 点「背单词」入口 → 弹出选词书弹窗，引导用户换书 |

## 六、需求详述 — 复习模块

### 6.1 核心原则

**复习模块的页面元素与交互同背单词页，完全复用。**

包括：两种卡片页面（四选一 + 主动回忆）、播放、熟、收藏、不太记得、进度条等。

### 6.2 与背单词的区别

| 维度 | 背单词 | 复习 |
|------|--------|------|
| 词源 | 未学过的新词 | 已学且到期的词（due_date ≤ 今天） |
| 入口文案 | "背单词" | "复习" |
| 结算页文案 | "学习了 X 个新词" | "复习了 X 个词" |

### 6.3 复习队列优先级

| 优先级 | 类型 | 逻辑 |
|--------|------|------|
| 1 | 困难词 | 标记的困难词（ease < 1.8）优先推送 |
| 2 | 逾期词 | due_date < 今天（欠债最久排最前） |
| 3 | 今日到期词 | due_date = 今天 |

### 6.4 复习中的 SRS 更新

**通过条件同背单词：四选一选对 + 主动回忆点记得 → 通过。其余情况 → 会话内重现（规则同 5.6）。**

| 通过方式 | SRS 行为 |
|----------|----------|
| 首次就通过（四选一选对 + 主动回忆记得） | interval = interval × ease，ease 不变 |
| 重学后通过 | interval = interval × 1.2，ease -= 0.1 |
| 5 次仍未通过 | interval = 1 天，ease -= 0.2（最低 1.3），标记困难词 |

具体计算示例：

```
某词当前状态：interval=4天, ease=2.5

首次通过 → interval = 4×2.5 = 10天，due = 今天+10
重学后通过 → interval = 4×1.2 = 5天，due = 今天+5，ease = 2.4
5次仍未通过 → interval = 1天，due = 明天，ease = 2.3
```

### 6.5 不进入复习模块的词

| 情况 | 原因 |
|------|------|
| 未学习的词 | 没经过背单词模块，无 SRS 参数 |
| due_date > 今天 | 还没到期，推太早损害间隔效果 |
| 标记「熟」的词 | 已移除，永不出现 |

### 6.6 复习会话结束条件

| 条件 | 行为 |
|------|------|
| 本组到期词全部完成 | → 跳转结算页 |
| 到期词较多时 | 按用户设置的每组数量（5/10/15）分批推送 |
| 用户主动退出 | → 已完成的正常保存 SRS，未完成的保持到期状态 |

### 6.7 复习边界场景

| 场景 | 规则 |
|------|------|
| 结算页点「再学一组」 | 继续进入复习页（下一批到期词），不切到背新词 |
| 剩余到期词不足一组 | 展示剩余全部到期词（如只剩 3 词则本组 3 词） |
| 全部到期词已复习完 | 「再学一组」按钮变为「已全部背完」，不可点击 |
| 复习中点「熟」 | 该词移除，本组进度条分母不变 |
| 数据写入时机 | 同背单词：一组完成后批量写入 SRS 更新 |

## 七、需求详述 — 单词首页

### 7.1 页面约束

一屏展示，不支持长页面。

### 7.2 页面结构

| 序号 | 元素 | 说明 |
|------|------|------|
| 1 | 首页上方 | 预留空间，填入 IP 与 slogan 等 |
| 2 | 卡片区 | 换词书入口（可点击）+ 今日学习进度（不可点击） |
| 3 | 打卡签到 | icon/卡片 |
| 4 | 背单词入口 | 点击进入背单词页 |
| 5 | 复习入口 | 点击进入复习页 |
| 6 | 开始学习按钮 | 交互同背单词入口 |

### 7.3 各元素详述

**1）首页上方**

- 主题色暂定浅绿色
- IP 该版本不设计
- 展示文字：안녕, 오늘도 화이팅～
- 根据文字设计 icon，保障页面协调与美观

**2）卡片区**

换词书入口可点击，今日学习进度不可点击。

换词书入口 → 点击跳转「选词书页」：

| 区域 | 功能 |
|------|------|
| 选词书区 | 展示：初级词汇、中级词汇、高级词汇，附图。点击选中该词书，支持更换 |
| 切换单词区 | 支持切换一组背词数（5/10/15） |

> **换词书进度规则：** 每本词书独立记录学习进度（current_position）。用户从初级切到中级后，再切回初级时从上次的位置继续（如学到第 51 词则继续第 51 词）。

**3）打卡签到**

| 状态 | 触发条件 | 交互 |
|------|----------|------|
| 未打卡 icon | 当日用户第一次进入 | 点击后切换为已打卡状态，奖励随机 10~28 积分 |
| 已打卡 icon | 用户当日完成打卡后 | 显示"已打卡 x 天"（累计天数，不清零），不可二次点击 |

> **签到规则：** 只计累计签到天数，不做连续签到判断，无中断惩罚。数据结构预留连续签到字段，后续版本可引入全勤额外积分体系。

**4）背单词入口**

点击进入背单词页（详见第五章）。显示待学习新词数量（如"背单词 · 10词"）。

**5）复习入口**

点击进入复习页（详见第六章），元素与交互同背单词页。显示待复习词数量（如"复习 · 12词"）。无到期词时显示"复习 · 0词"，入口不置灰，仍可点击（进入后 toast 提示"太棒了，全部已复习！"）。

### 7.4 冷启动引导

新用户首次进入小程序时，弹出引导弹窗：

| 步骤 | 内容 |
|------|------|
| 1 | 选择词书（初级/中级/高级） |
| 2 | 选择每组背词数量（5/10/15） |

- 弹窗无关闭按钮（不设叉号）
- 用户点击弹窗外区域：默认选择「初级词汇」+ 10 词/组，直接进入首页
- 完成选择后进入首页，后续可在选词书页修改

## 八、需求详述 — 完成页（结算页）

### 8.1 页面结构

```
┌────────────────────────────┐
│                            │
│         🎉🎉🎉             │  ← 大图标 + Lottie 庆祝动画

│                            │
│  ┌───────────┬───────────┐ │

│  └───────────┴───────────┘ │
│                            │
│  [  再学一组  ] [休息一下]   │  ← 并列，再学一组更大+强调色
│                            │
│         🔗 分享            │  ← 小号分享按钮
└────────────────────────────┘
```

### 8.2 页面元素说明

| 元素 | 说明 |
|------|------|
| 大图标 + 动画 | 顶部庆祝图标，进入页面时播放 Lottie 动画（撒花/星星等），播放一次不循环 |
| 鼓励文案 | 随机展示，候选池：오늘도 잘했어요! / 太棒啦！/ 계속 화이팅! / 今天也很努力呢！ |
| 本次学习完成 | 固定文案，紧跟鼓励文案下方 |
| +15 积分 | 当日首组展示，非首组该行隐藏 |
| 今日数据 | 横向并列：今日学习 X 词（当日所有组累计） / 学习时长 X 分钟（当日累计） |
| 再学一组 | 主按钮（更大、主题色填充），逻辑见 8.3 |
| 休息一下 | 次按钮（更小、边框/灰色），点击回到单词首页 |
| 分享按钮 | 小号，分享小程序链接到微信/朋友圈/QQ |

### 8.3 结算页按钮逻辑

| 来源场景 | 「再学一组」行为 |
|----------|----------------|
| 背单词 → 结算页 | 开始下一组新词 |
| 背单词 → 词书全部背完 | 按钮变为「已全部背完」，不可点击 |
| 复习 → 结算页 | 继续下一批到期复习词 |
| 复习 → 全部到期词已复习完 | 按钮变为「已全部背完」，不可点击 |

### 8.4 积分展示规则

- 当日首组（背单词或复习）：结算页显示 "+15 积分" 行
- 非首组：该行不展示

## 九、单词归属规则与生命周期

### 9.1 单词生命周期

```
         背单词模块                    复习模块
        ┌────────┐                  ┌────────┐
        │        │   完成学习        │        │
 新词 ──→│ 首次   │──(设interval=1)──→│ 到期时 │──→ 根据反馈
        │ 认知   │   due=明天        │ 推送   │    更新SRS
        └────────┘                  └───┬────┘
             │                          │
             │ "熟"                      │ 选对/记得 → interval×ease
             │ 永不再出现                │ 不太记得/模糊 → interval×1.2
             ↓                          │ 选错/忘记 → interval=1
        ┌────────┐                      │
        │ 已移除  │                      │
        │ 永不   │                      │
        │ 出现   │                      │
        └────────┘                      │
                                        │
                                ┌───────┘
                                ↓
                         interval 持续增长
                         间隔越来越长
```

### 9.2 单词状态定义

| 状态 | 条件 | 所属模块 |
|------|------|----------|
| 未学习 | 无 SRS 参数 | 背单词模块推送 |
| 学习中 | interval < 7 天 | 复习模块（到期时） |
| 熟悉 | 7 ≤ interval < 30 天 | 复习模块（到期时） |
| 已掌握 | interval ≥ 30 天 | 复习模块（到期时，频率极低） |
| 已移除 | 用户点「熟」 | 永不出现在任何模块 |

## 十一、非功能性需求

| 场景 | 规则 |

## 十四、积分系统

### 14.1 积分获取

| 行为 | 积分 | 说明 |
|------|------|------|
| 每日打卡签到 | 随机 10~28 | 每日首次点击签到触发 |

### 14.2 积分用途

> MVP 版本为纯数据展示。后续版本计划引入激励体系：兑换勋章、解锁 IP 形象等。
