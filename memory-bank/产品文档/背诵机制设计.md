## 设计原则

| 原则 | 依据 |
|------|------|
| 主动回忆 > 被动识别 | 认知心理学：提取练习（Retrieval Practice）记忆效果是重读的 3 倍 |
| 先难后易 | 经济学：先付出成本再获得回报，符合"投入-回报"心理预期 |
| 短会话高频次 | 艾宾浩斯遗忘曲线：间隔短、次数多 > 一次性长时间 |
| 即时反馈 | 行为心理学：反馈延迟超过 3 秒，学习效率下降 40% |

## 一、单次学习会话结构

背单词模块和复习模块为**独立入口**，用户分别进入：

```
背单词会话 = 仅新词（5/10/15 可选）
复习会话   = 仅到期词（按优先级排序，每组 10 词）
```

两个模块页面元素与交互完全一致，区别仅在于词源和 SRS 计算逻辑。

## 二、单词学习流程（两种页面交替）

### 页面类型 A：四选一选择题

```
展示韩文 + 播放icon + 收藏icon + 「熟」按钮
         ↓
4 个选项（1 正确 + 3 干扰项，同词性）
         ↓
选对 → 正确标绿 → 展示释义详情 → 「下一词」
选错 → 错误标红+正确标绿 → 展示释义详情 → 「下一词」
         ↓
底部「不太记得」→ 展示同正确答案详情
```

### 页面类型 B：主动回忆

```
展示韩文 + 播放icon + 收藏icon + 「熟」按钮
         ↓
空白区域（用户自行回忆）
         ↓
底部三个按钮：「记得」「模糊」「忘记」
         ↓
点击任意按钮 → 展示正确释义详情
```

### 答案揭示详情页（两种页面共用）

展示：韩文 + 发音标注 + 词性 + 正确释义 → 「下一词」按钮

## 三、SRS 间隔调度算法（简化版）

### 算法溯源与理论依据

本算法基于 **SM-2**（SuperMemo Algorithm 2）简化改造而来。

**学术脉络：**

| 年份 | 里程碑 | 核心贡献 |
|------|--------|---------|
| 1885 | Ebbinghaus 遗忘曲线 | 首次量化证明：记忆随时间指数衰减，但每次复习都会拉平曲线 |
| 1972 | Leitner 卡片箱系统 | 将卡片按掌握度分箱，答对升箱（间隔拉长）、答错回第一箱 |
| 1987 | Wozniak SM-2 算法 | 引入 ease factor（难度因子），让间隔根据个体表现动态调整 |
| 2006 | Roediger & Karpicke 提取练习实验 | 证明"考自己"比"重读"记忆保持率高 80%（1 周后） |
| 2022 | FSRS（Free Spaced Repetition Scheduler） | 基于 17000+ 用户数据统计优化的开源 SRS，Anki v23+ 采用 |

**我们选 SM-2 简化版而非 FSRS 的原因：**
- 小程序端计算资源有限，SM-2 逻辑简单可离线运行
- 1624 词的小词库不需要 FSRS 的复杂统计模型
- SM-2 经 37 年验证，用户体感稳定

---

### SM-2 原始公式（我们的改造基础）

```
原始 SM-2（Wozniak, 1987）：

I(1) = 1 天
I(2) = 6 天
I(n) = I(n-1) × EF    （n ≥ 3）

EF' = EF + (0.1 - (5-q) × (0.08 + (5-q) × 0.02))
     其中 q = 用户评分（0~5）

约束：EF ≥ 1.3
```

---

### 我们的反馈与 SRS 映射

用户操作分为两组（对应两种页面），但 SRS 行为等价：

| 页面类型 | 用户操作 | 等价含义 | SM-2 q 值 |
|----------|----------|----------|-----------|
| 四选一 | 选对 | 完美回忆 | q = 5 |
| 四选一 | 不太记得 | 犹豫但知道 | q = 3 |
| 四选一 | 选错 | 完全不记得 | q = 1 |
| 主动回忆 | 记得 | 完美回忆 | q = 5 |
| 主动回忆 | 模糊 | 犹豫但知道 | q = 3 |
| 主动回忆 | 忘记 | 完全不记得 | q = 1 |

---

### 核心参数

每个单词维护 3 个字段：

```json
{
  "interval": 1,
  "ease": 2.5,
  "due_date": "2026-05-30"
}
```

**为什么 ease 初始值是 2.5？**
→ SM-2 原论文实验得出：普通难度词汇的最优初始因子为 2.5，即每次成功回忆后间隔翻 2.5 倍最接近真实遗忘速率。

---

### 背新词时的 SRS 设定

| 操作 | interval | ease |
|------|----------|------|
| 选对 / 记得 | 1 天 | 2.5（初始） |
| 不太记得 / 模糊 | 1 天 | 2.3 |
| 选错 / 忘记 | 会话内重现 | 1.3 |

### 复习时的 SRS 更新

| 操作 | interval 变化 | ease 变化 |
|------|--------------|-----------|
| 选对 / 记得 | interval × ease | ease 不变 |
| 不太记得 / 模糊 | interval × 1.2 | ease - 0.1 |
| 选错 / 忘记 | 重置为 1 天 | ease - 0.2（最小 1.3） |

**ease 下限 1.3 的含义：** 即使一个词反复忘记，间隔最慢也会以 ×1.3 的速率增长（1→1.3→1.7→2.2天...），不会永远停在每天复习，避免用户挫败。

**ease 上限 3.0 的含义：** 防止某些词因为连续答对而间隔跳得太快（如 30→90 天），超出人类真实记忆极限。

### 复习理想路径示例

**全部选对/记得：**
```
第1次复习 → 1×2.5 = 3天后
第2次复习 → 3×2.5 = 7天后
第3次复习 → 7×2.5 = 18天后
第4次复习 → 18×2.5 = 45天后
```

**全部模糊/不太记得：**
```
第1次复习 → 1×1.2 = 1天后（向上取整）
第2次复习 → 1×1.2 = 1天后
第3次复习 → 1×1.2 = 2天后
第4次复习 → 2×1.2 = 2天后
第5次复习 → 2×1.2 = 3天后
```

## 四、会话内重学机制

当用户选错或点「忘记」时：

```
当前位置: 第 3 个词（사랑）→ 选错/忘记
                ↓
该词插入队列末尾（间隔 3~5 个词后再次出现）
                ↓
再次出现时，再出一次题
                ↓
若选对/记得/模糊 → 通过，设置 SRS
                ↓
若再次错/忘记 → 再次插入末尾（最多循环 3 次）
                ↓
3 次仍错 → 标记为困难词（ease=1.3），明天复习优先推送
```

## 五、单词状态分级

| 状态 | 条件 | 说明 |
|------|------|------|
| 未学习 | 无 SRS 参数 | 背单词模块推送 |
| 学习中 | interval < 7 天 | 复习模块到期时推送 |
| 熟悉 | 7 ≤ interval < 30 天 | 复习模块到期时推送 |
| 已掌握 | interval ≥ 30 天 | 复习频率极低 |
| 已移除 | 用户点「熟」 | 永不再出现（背单词/复习均不推送） |

---

## 六、每日学习量控制

### 新词量
用户可选：5 / 10 / 15 词/次（在选词书页设置）

### 复习队列优先级
```
1. 困难词（ease < 1.8）
2. 逾期词（due_date < 今天，欠债最久排最前）
3. 今日到期词（due_date = 今天）
```

---

## 七、「熟」按钮机制

| 项目 | 说明 |
|------|------|
| 位置 | 每个单词卡片上均有 |
| 行为 | 该词标记为"已移除"，永不出现在背单词和复习模块 |
| 查看 | 「我的」→「近日已学」→「已完全记得不再出现」tab |
| 适用场景 | 用户已完全掌握的词（如韩剧常见词） |

## 八、为什么这样设计（PM 视角）

| 决策 | 心理学/经济学依据 |
|------|-----------------|
| 两种页面交替（四选一+主动回忆） | 多样化练习效应：变换形式防止"自动驾驶"，强化深度加工 |
| 四选一降低门槛 | 有选项兜底，减少完全空白的挫败感 |
| 主动回忆提升深度 | 无提示的自由回忆，记忆留存率高 2~3 倍 |
| 会话内重学 | 即时纠正 > 隔天纠正，符合"最近发展区"理论 |
| 新词量可调 | 给用户控制感（自我决定理论），减少被动学习的抗拒 |
| 不显示遗忘曲线 | MVP 阶段用户不需要看算法，只需感受"越来越记得住" |
| 「熟」按钮 | 尊重用户自主判断，避免强制复习已掌握词的无效时间 |
