## 二、逐产品深度拆解

### 1. 不背单词 — 审美 + 语境 + 主动回忆

#### 产品概述
以"最美背单词 App"为品牌心智，用高品质壁纸 + 真实语境例句打造沉浸体验。学习机制科学：先遮挡释义让用户主动回忆，再展示语境强化。

#### 页面结构（3 Tab）

| 页面 | 功能 |
|------|------|
| 学习（首页） | 全屏壁纸 + Learn / Review 两个入口 |
| 我的内容 | 随身听、听写、词书、句库、笔记 |
| 仪表盘 | 学习数据 + 日历签到 |

#### 背诵核心流程

```
阶段一：主动回忆
┌────────────────────────────┐
│  unattractive              │  ← 只展示单词
│  /ˌʌnə'træktɪv/           │  ← 发音可播放
│  ████████████              │  ← 释义被遮挡
│                            │
│  瞬间想起词义，选「认识」    │  ← 引导文案
│  思考后想起词义，选「模糊」  │
│                            │
│  认识(🟢)  模糊(🟡)  忘记了(🔴) │
└────────────────────────────┘

阶段二：揭示 + 语境强化（选"认识"或"模糊"后）
┌────────────────────────────┐
│  un·attract·ive ✅          │  ← 音节拆分
│  adj. 不吸引人的，难看的     │  ← 释义揭示
│  ┌──────────────────────┐  │
│  │ 真实语境例句（影视来源）│  │  ← 关键词加粗
│  │ + 中文翻译             │  │
│  └──────────────────────┘  │
│  ┌──────────────────────┐  │
│  │ 词组搭配 + 释义        │  │
│  └──────────────────────┘  │
│  [词组搭配][派生][词根][近义] │  ← 多维信息切换
│                            │
│  下一词(🟢)    记错了(🔴)   │  ← "记错了"可后悔修正
└────────────────────────────┘
```

#### 复习模式 = 四选一

- 展示单词 + 发音
- 提示"先回想词义再选择，想不起来看答案"
- 4 个同词性干扰项
- 答错标粉 + 正确标绿

#### 视觉风格

- 首页：全屏高品质摄影壁纸，零 UI 噪音
- 学习页：柔和渐变毛玻璃背景（天蓝→米色→灰褐）
- 按钮：文字 + 彩色下划线（非实心），轻盈克制
- 卡片：半透明毛玻璃，无描边
- 整体：高级感、审美导向、杂志质感

#### 亮点

1. 三级反馈 + 释义遮挡 = 真正的主动回忆
2. "记错了"后悔机制——减少算法误判
3. 认识后仍展示完整语境（不跳过学习机会）
4. 引导文案降低决策犹豫（"瞬间想起选认识"）
5. 全屏壁纸首页 = 打开即审美享受
6. 极简 3 Tab 导航

#### 槽点

1. 英语专属，韩语空白
2. 壁纸资源大，不适合小程序
3. Learn 3486 大数字可能劝退新用户

### 2. 疯狂背单词 — 应试四选一 + 多模式练习

#### 产品概述
面向专升本/四六级/考研等应试人群的背词工具，核心是四选一选择题 + 多种练习模式 + 遗忘曲线可视化。功能全面但偏"工具感"。

#### 页面结构（4 Tab）

| 页面 | 功能 |
|------|------|
| 单词（首页） | 今日计划 + 新学/复习按钮 + 自由练习入口 |
| 统计 | 学习日历 + 成就 + 遗忘曲线对比图 |
| 词典 | 查词工具 |
| 我的 | 个人设置 |

#### 背诵核心流程 = 四选一选择题

```
┌────────────────────────────┐
│  ← 2/10         熟 ☆ ⊙    │  ← 进度 + 工具按钮
│                            │
│  express                   │  ← 大字展示单词
│  美 [ɪk'spres] 🔊         │  ← 音标 + 发音
│                            │
│  从下列四个选项中，选择正确释义 │
│  ┌────────────────────┐    │
│  │ n. 对话；            │    │
│  ├────────────────────┤    │
│  │ v. 表达；表示；  ✓    │    │  ← 绿色正确
│  ├────────────────────┤    │
│  │ against             │    │
│  │ prep. 反对；碰；✗    │    │  ← 红色错误
│  ├────────────────────┤    │
│  │ adj. 喜爱的；        │    │
│  └────────────────────┘    │
│                            │
│       [ 继续 ]              │  ← 黄色按钮
└────────────────────────────┘
```

#### 单词详情页（答题后展示）

- 释义 + 双语例句（含发音）
- 助记内容（谐音故事 + 卡通插图）
- 助记视频 / 笔记 tab
- 查词典入口

#### 学习计划设置

- 新学单词量：5 词/天（可调）
- 复习任务上限：新学词的 5 倍
- 智能复习开关（减少熟词复习）
- 背单词模式：轻松模式 / 其他
- 出词方式：系统推荐
- 预估完成计划天数

#### 自由练习（5 种模式）

| 模式 | 形式 |
|------|------|
| 听力训练 | 听音选义 |
| 拼写练习 | 看义拼词 |
| 列表刷词 | 快速浏览 |
| 释义巩固 | 看义选词 |
| 更多 | … |

#### 统计页亮点

- 学习日历（打卡日标火焰）
- 学习成就：天数 / 时长 / 单词数
- 周学习时长柱状图
- **遗忘曲线对比图**：艾宾浩斯理论曲线（蓝，急降到~20%） vs 我的实际曲线（橙，维持~90%）

#### 视觉风格

- 主色：黄色品牌强调色
- 背景：白底 + 浅灰卡片
- IP：黑猫简笔画
- 按钮：大圆角黄色按钮
- 整体：活泼、功能密集、工具感

#### 亮点

1. 遗忘曲线对比图——直观展示"SRS 在保护记忆"
2. 四选一门槛极低，碎片时间友好
3. 复习上限 = 新词×5，简单规则
4. 5 种练习模式多维强化
5. 退出挽留弹窗（"按计划学习效果更佳"）

#### 槽点

1. 四选一 = 被动识别，记忆深度有限
2. 干扰项质量不高（跨词性混入）
3. 界面信息密集、留白少
4. 588 天完成计划的数字劝退
5. 无打卡连续天数（Streak）社交激励

### 3. 韩语U学院 — 韩语垂直 + 浏览式学习

#### 产品概述
韩语综合学习 App，包含背词、课程、发音等模块。背词部分走纯浏览路线：展示释义 + 例句，用户自判"继续"或"太简单"。是唯一的韩语竞品参考。

#### 页面结构（5 Tab）

| 页面 | 功能 |
|------|------|
| 背词 | 首页，今日计划 + 打卡 |
| 课程 | 韩语课程 |
| 学习中心 | 综合资源 |
| 发音 | 发音训练 |
| 我的 | 个人数据 |

#### 背诵核心流程 = 纯浏览

```
每次 5 词一组：

┌────────────────────────────┐
│  ✕         0/5             │
│                            │
│  간단하다   🔊    [★收藏]  │  ← 韩文 + 发音 + 收藏
│                            │
│  【形容词】                  │
│  1. 简单。                   │  ← 释义直接展示
│  2. 简便。简单。             │
│  ─────────                  │
│  💡 例句                    │
│  이 설비의 구조는 간단하다.  │  ← 韩文例句 + 发音
│  这个设备的结构简单。        │  ← 中文翻译
│                            │
│  (更多例句 >)               │
│  [纠错]                     │
├────────────────────────────┤
│  [继续背词]     [太简单]    │  ← 仅两个选项
└────────────────────────────┘
```

- **继续背词** = 标记为"初识"，进入 SRS 队列
- **太简单** = 直接标记为"掌握"，跳过后续复习
- **没有"忘了"按钮，没有测试，没有主动回忆**

#### 词书系统

- 精选词汇：初级1(387词) / 初级2(491词) / 中级1(712词)
- 实用词汇：初级1(402词) / 初级2(295词) / 中级1(228词)
- TOPIK 考试专题
- 收藏词本（用户自建）

#### 我的词汇管理

- 分 tab：今日单词 / 常错单词 / 正在学习 / 掌握单词
- 每词显示：韩文 + 释义 + 发音按钮 + 状态标签（初识/掌握）

#### 视觉风格

- 主色：蓝色品牌色
- 背景：白色为主，背词页蓝色渐变顶部
- IP：冬日小鸡（可爱插画风）
- 整体：偏女性化、可爱、课堂感

#### 亮点

1. "太简单"快速跳过——避免在已知词上浪费时间
2. 韩文问候语增加沉浸感（안녕하세요!）
3. 韩文例句 + 发音播放
4. 收藏/生词本功能
5. 纠错入口（众包改善）
6. 词书分类覆盖面广

#### 槽点

1. **纯浏览无主动回忆** = 记忆效果极差
2. 反馈只有"继续/太简单"二级，缺少"忘了"
3. 大量词无例句（内容覆盖不完整）
4. 释义不精炼（混入法律术语、繁体字）
5. 无 SRS 间隔调度（顺序刷词）
6. 5 Tab 导航过于分散
7. 掌握度判定无验证机制

### 4. 多邻国 Duolingo — 游戏化之王

#### 产品概述
全球最成功的语言学习 App，以行为心理学驱动的游戏化设计著称。不是纯背单词工具，而是综合语言技能训练平台。

#### 页面结构（5 Tab）

| 页面 | 功能 |
|------|------|
| 学习路径 | 树形/线性关卡进度 |
| 练习 | 已学内容强化 |
| 个人 | 统计 / XP / Streak |
| 任务 | 每日任务/成就 |
| 排行榜 | 社交竞争 |

#### 核心游戏化元素

| 机制 | 心理学原理 |
|------|-----------|
| Streak（连续天数） | 损失厌恶——断签焦虑 |
| XP + 排行榜 | 社交比较 + 竞争驱动 |
| 红心（Hearts） | 稀缺感——错误有代价 |
| 宝石 + 道具 | 可变奖励 |
| 5 分钟短会话 | 极低启动门槛 |
| 进度路径 | 蔡格尼克效应（未完成冲动） |
| IP 形象（猫头鹰 Duo） | 情感化连接 |

#### 学习流程（从截图观察）

1. **字母/基础教学**：韩文字母学习页（ㅓ/eo 的配对练习）
2. **关卡路径**：线性进度，每关解锁新内容
3. **练习形式多样**：
   - 翻译题（英→韩 / 韩→英）
   - 选择题（图片+文字配对）
   - 拼词题
   - 听力题
4. **即时反馈**：每题立判对错 + 正确答案展示

#### 视觉风格

- 鲜艳彩色（绿色为主 + 多彩辅助）
- 圆润卡通 UI，大量动效
- IP 无处不在
- 整体：游乐场感、低压力、高趣味

#### 亮点

1. 游戏化设计教科书——Streak 是最强留存钩子
2. 多种练习形式（不止选择题）
3. 即时反馈 + 错误后立即纠正
4. 5 分钟短会话，极低门槛
5. 进度可视化（路径/地图形式）

#### 槽点

1. 词汇深度不足（偏句子，非系统背词）
2. 韩语内容质量一般（翻译腔）
3. 对已有基础的用户太慢
4. 游戏化过度可能让用户"在玩而非在学"
5. 重 App 形态，无法在小程序复现

## 四、综合洞察

### 市场空白与机会

1. **韩语 + 科学记忆 = 空白市场**
   - 韩语U学院有韩语但无科学机制
   - 不背单词有科学机制但无韩语
   - 没有产品同时做好"韩语 + 主动回忆 + SRS"

2. **小程序形态 = 无竞争**
   - 所有竞品均为原生 App
   - 我们的 1624 词精选词库完美适配小程序轻量形态
   - 即开即用，微信社交裂变

3. **审美差异化 = 低成本高感知**
   - 韩语U学院视觉平庸
   - 我们用韩式极简（已有风格 Demo 方向）即可形成明显区隔

### 必须做的（MVP 核心）

| 功能 | 来源 | 优先级 |
|------|------|--------|
| 主动回忆（遮挡释义） | 不背单词 | P0 |
| 三级反馈（认识/模糊/忘了） | 不背单词 + 墨墨 | P0 |
| SRS 间隔复习算法 | 墨墨 + 疯狂背单词 | P0 |
| "记错了"后悔修正 | 不背单词 | P0 |
| 认识后仍展示完整信息 | 不背单词 | P0 |
| 反馈引导文案 | 不背单词 | P0 |
| 韩文发音播放 | 韩语U学院 | P0 |
| 今日学习量展示 | 全部竞品 | P0 |
| "太简单"快速跳过 | 韩语U学院 | P1 |
| 连续打卡（Streak） | 多邻国 + 疯狂背单词 | P1 |
| 学习完成页 + 数据统计 | 全部竞品 | P1 |
| 退出挽留提示 | 疯狂背单词 | P2 |

| 多种练习模式（听/写） | 疯狂背单词 | V3 |
| 随身听（音频复习） | 不背单词 | V3 |

### 坚决不做的（MVP 排除）

| 功能 | 原因 |
|------|------|
| 全屏壁纸/毛玻璃 | 小程序包体限制 + 性能 |
| 5 Tab 复杂导航 | 功能过重 |
| 课程/发音独立模块 | 偏离背词核心 |
| 排行榜/社区 | 冷启动无用户基础 |
| 词根词缀/派生体系 | 韩语不适用 |
| 助记视频 | 制作成本高 |
| 游戏化关卡路径 | 开发复杂度过高 |

## 五、我们的差异化定位

```
一句话定位：
韩语精选 1624 词 × 科学主动回忆 × 小程序即开即用
```

| 维度 | 我们的选择 | 依据 |
|------|-----------|------|
| 语种 | 韩语专精 | 市场空白，我们有母语级词库 |
| 机制 | 主动回忆 + 三级反馈 + SRS | 不背单词验证的最优方案 |
| 形态 | 微信小程序 | 轻量、即开即用、社交裂变 |
| 审美 | 韩式极简 | 对标不背单词审美水准，区别于U学院平庸 |
| 词库 | 1624 词精选 | 小而精，不贪多，对标 TOPIK 分级 |
| 交互 | 极简（≤3 页面） | 小程序天然要求精简 |
